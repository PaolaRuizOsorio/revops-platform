# RevOps Platform
Plataforma de integración entre Salesforce y Python: sincronización segura por API, arquitectura limpia y CI/CD.

## Estado
En construcción. Actualmente se están definiendo las bases del proyecto.

## Problema que resuelve

Los equipos de ventas guardan en Salesforce los datos de los clientes y de los posibles clientes, la información de sus contactos y el registro y seguimiento de las ventas.

Cuando otras áreas necesitan esa información, acceder a ella resulta difícil. Este proyecto automatiza ese acceso de forma segura, por medio de una API y una base de datos propia, para que quien la necesite pueda consultarla de manera rápida y eficiente.
